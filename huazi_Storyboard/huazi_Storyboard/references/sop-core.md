# 分镜图制作 SOP 详版（六步法）

> 核心原则：图生视频前，所有空间逻辑必须在分镜图层面解决，不留给视频模型。
> 工具链示例：RunningHub 无限画布（画图）→ 豆包/任意大模型（提示词整理）→ ComfyUI 工作流（MiniMax/Seedance 出片）。本 SOP 不绑定具体平台，输出物为通用提示词。

---

## 第 0 步：项目初始化

1. 与用户确认：项目名称（文件夹名"某某"）、剧情范围、人物清单、场景清单、原文位置。**若用户未说明画风，必须先询问风格**（电影写实风 / 3D动漫风 / 3D真人风 / 2D动漫风 / 国漫风等），确认后写入 00 文件"本资产风格声明"，全项目所有提示词统一携带该风格词（词库见模板库第六节），不得混用。
2. 运行骨架脚本创建 `{名称}分镜图设定/` 文件夹（工作区或指定目录）。
3. 检查 4 类前置资产是否齐备：

| 资产 | 要求 | 缺失时的补救 |
|---|---|---|
| 人物资产卡版面图 | 每角色一张：左43%主肖像/中三视图/下方特点与服装特写/右眉眼口鼻耳发型特写，左上角代号 | 用模板库 1.1 人物资产卡（五件套：中文对照/英文/纯图版/版面/反向）生成投喂提示词 |
| 场景资产卡+三视图 | 主视角+锚点特写版面卡；差异化构件场景另做三视图（模板库 1.5） | 单张场景图信息不够，先按模板库 1.2 出资产卡再补 1.5 三视图 |
| 场景俯视图 | 装修设计平面图式"上帝视角"（模板库 1.4） | 先主视角后俯视图；直接从单张图做俯视图会缺背面 |
| 场景变体 | 光照/时段/状态有差异的场景，每个变体一条完整提示词（模板库 1.3） | 逐个变体写，禁止"其余变体同理" |
| 剧情原文/大纲 | 已有章节文本或剧本 | 用户提供或确认改编范围 |

## 第 1 步：素材清单

产出 `00_项目信息与素材清单.md`：

- 项目名称、剧情范围、总时长估算
- 资产表：每项标注状态（已有/缺失）+ 来源路径或补全提示词（每个缺失资产给五件套提示词：中文对照/英文/纯图版/版面/反向，变体逐个写）
- **资产命名与挂载对应表（必含）**：资产代号 ↔ 03 分镜 @图片N ↔ 05 视频 @ref_image_N 三处一致
- 人物表：角色名 → 资产代号（CH01…）→ 一句话外貌锚点（服装颜色、标志道具、疤痕胎记等——这些会写进每段物理规则与资产卡特点特写区）
- 场景表：场景名 → 资产代号（S01-…-MV/FP/RV）→ 一致性锚点 3-5 个（墙体位置、家具、光照）

## 第 2 步：空间物理规则总表

产出 `01_空间物理规则总表.md`，每个场景一份。8 项必查：

1. **空间尺寸**：多少平方米、纵深、过道宽度（不写必画成豪华大厅）
2. **每人初始位置**：坐/站/趴什么姿态、靠什么（窗边桌/柜台/讲台）
3. **朝向与相对关系**：谁面向谁、谁在谁右侧、间距多少米
4. **互动触发顺序**：谁先动、谁看到什么才反应（"发现问话之后才开始互动"）
5. **人物数量上限**："除这N人外没有任何人"（不写必路人乱入）
6. **避免同框**："避免三人同框"——控制画面复杂度
7. **AI 难生成画面规避**：文字密集区（招牌/号码牌/规则卡/屏幕）虚化为色块纹理，数字文字后期字幕补
8. **负面要求**："生成结果不要有任何的字幕、备注和标识，以纯画面的形式给我即可"

外加：**贯穿道具锚点**（主角的手表/标志服装等，每段提示词都要重申）。

## 第 3 步：shot 表

产出 `02_分镜总表_shot表.md`。总表列：镜号｜段｜时长｜景别｜运镜｜情节描述｜情绪/备注｜节奏标注。

- 每段 4 镜约 10 秒；每镜 2.5-3 秒
- 一章 40-60 秒 ≈ 4-5 段
- 对话戏设计正反打（A 说/B 听交替）+ 一个过肩双人镜头
- **节奏标注列必填**：铺垫 / 爆点 / 爽点 / 反转 / 钩子，逐镜标注
- **每集最后一镜必须是钩子帧**（悬念/反转/危机未解的定格，不揭示答案）
- **爆点放段尾**：强冲突镜头压在段尾，铺垫镜在前；全章至少 1 个爆点
- **爽点紧跟压抑**：主角智斗得逞/打脸/预言应验等爽点镜安排在压抑铺垫之后释放
- **反转提前埋伏笔**：揭示前一镜安排"可回看的伏笔画面"（如空椅子特写），反转镜头直接回扣
- 验收时（04 文件）核对"铺垫在前、爆点在后、钩子定格收尾"三段节奏
- 闪回/插帧类镜头标注"后期处理，不进本组生成"

## 第 4 步：分段分镜图提示词（核心交付）

产出 `03_分段分镜图提示词.md`。每段一条完整提示词，fenced code block，结构：

```
帮我生成4张10秒左右的真人电影级别分镜图。
1️⃣ @图片1 是【角色A】的全身形象参考图；
2️⃣ @图片2 是【角色B】的全身形象参考图；
👉 @图片4 内【场景名】空间场景逻辑参考图；

其中物理规则：
（共用规则逐条 + 本段特化规则，含人数/位置/面积/朝向/触发顺序/虚化规避）

以下是故事剧情内容：
梗概：……
场景：……
shot1：时长：3秒；景别：全景；运镜：固定；情节描述：……。情绪/备注：……。
（shot2-4 同格式）

生成结果不要有任何的字幕、备注和标识，以纯画面的形式给我即可。
```

每条提示词前注明：**本段 @图片 挂载清单**（图1=哪个角色资产、图4=哪个场景俯视图）。

段特化规则要点：
- 开场段：单人入画，其余人物排除
- 对话段：双方站位/间距/朝向/全程不换位
- 新角色入场段：入场动线（从哪进、沿什么走、停在哪）
- 收尾段：钩子帧的具体动作链（谁拿起什么、放在哪里）

## 第 5 步：验收与拼版

产出 `04_验收与拼版清单.md`。

逐格验收五项口诀：**人数对、位置对、大小对、结构对、无字幕**，另加项目特有锚点项（列出该项目的道具/位置/服装锚点，逐项打勾）。

翻车修复对照表（现象→原因→修复）：

| 现象 | 原因 | 修复 |
|---|---|---|
| 画面人满为患 | 未约束人数 | 物理规则加"除N人外没有任何人" |
| 空间变大变豪华 | 未约束面积 | 加"只有N个平方" |
| 建筑结构矛盾 | 空间参考未锚定 | 确认俯视图已挂载且规则重申结构 |
| 人物换脸/换装 | 资产未被正确引用 | 核对 @图片N 对应关系 |
| 出现字幕水印 | 未加负面要求 | 加"不要任何字幕、备注和标识" |
| 文字区数字乱码 | AI 难生成文字 | 改为虚化色块 + 后期字幕 |

不合格处理：**改物理规则重生成，不抽卡**。

拼版流程：四宫格裁成 4 张 → 按镜号挑选拼九宫格（3×3）→ 一段 30 秒剧情 ≈ 2 组九宫格 → 打包为视频环节的"分镜图资产"。

## 第 6 步：视频环节五锁结构

产出 `05_视频环节提示词_五锁结构.md`，每段一条成品：

```
[项目规格]
项目：15秒，画幅：16:9，帧基准：24fps，真人电影级写实（题材）剧情片。
场景：（场景名）。N个连续分镜，严格次序表现。
叙事链：（一句话动作链）。物理规则为最高优先级：（关键空间约束摘要）。

[STYLE LOCK]
（风格质感：环境材质、光照方向与时段、色调锁定、气氛。加负面：不使用……）

[REFERENCE LOCK]
@ref_image_0｜（角色A）唯一人物身份参考：四视图拼版……全片保持同一张脸，
不得衍生新角色、新发型或新色卡。
（逐个参考图写）
@ref_image_N｜（场景）空间与构图逻辑参考：……作为内景唯一制图与连贯性
锚定参考，构图不得改动或重建场景。

[PHYSICAL / CONTINUITY LOCK]
一、空间尺度：……
二、人物数量：……
三、贯穿锚点：……
（逐条编号）

HARD CUT
[SHOT 01 | 00:00.000—00:02.500] 景别、运镜：情节描述。焦段/景深。情绪。
结束画面定格于……
（逐镜，台词注明"口型与中文台词严格同步：'……'"）

[AUDIO LOCK]
含中文同期对白，无旁白、无歌声、无背景音乐。
00:00—00:05：（环境音）……
（分时段音效表）
```

**注意事项**：
- 视频提示词中的参考图编号（@ref_image_N）与上传顺序一一对应，文件中注明上传顺序表
- 每镜必须写"结束画面定格"——这是镜头衔接的关键
- 台词口型同步要求显式写明

## 输出格式约定

- 默认全部输出 .md；用户要求 docx 且环境支持时转换，否则保留 .md 并说明
- 所有提示词放 fenced code block，变量全部填好，不留半成品
- 文件头部写明：项目名、剧情范围、生成日期、与上游文件的对应关系
