# 工具适配指南（豆包主路径版）

> 主路径：**豆包一站式**——生图（Seedream）与视频（Seedance）全部在豆包 App/网页版完成，不需要 ComfyUI、RunningHub 或即梦。
> 本技能两套产出（分镜图提示词、视频提示词）都给出了豆包格式的用法与转换规则。
> 信息核对日期：2026-11-24（模型迭代快，使用前以豆包内实际入口与会员权益为准）

## 一、平台总览（用户未指明平台时，先询问再按对应路径产出）

| 环节 | 豆包（默认主推） | 即梦 | RunningHub | LiblibAI | 本地 ComfyUI/MiniMax |
|---|---|---|---|---|---|
| 生成分镜图 | 对话生图（Seedream 组图模式） | 智能画布/组图 | RHTV 无限画布 或 ComfyUI 工作流 | 极简生图器（多模型聚合）| ComfyUI 工作流 |

## 二、豆包能力速查（2026-11 核对）

### 生图：Seedream 系列（豆包对话直接用）

| 能力 | 说明 |
|---|---|
| 多参考图 | Seedream 5.0 lite / 4.5 / 4.0 最多 **14 张**；5.5 / 5.0 pro / flash 最多 **10 张** |
| 组图模式 | "参考@图片1…，生成一组4张内容连贯的图"——分镜图首选，4 张独立出图、分辨率不损失 |
| 文字渲染 | 可靠，大字号短文字可直出（标题、单块号码牌、钟面数字可尝试） |
| 分辨率 | 1K-3K 按模型版本；比例含 16:9 / 9:16 / 1:1 等 |
| 改图 | 对话式编辑：直接说"把图中××改成××"重出图 |

### 视频：Seedance 系列（豆包 App 新建对话 → 视频生成）

| 项目 | Seedance 2.0（含 fast/mini） | Seedance 2.5（专业版权益） |
|---|---|---|
| 单条时长 | **4-15 秒** | **4-30 秒** |
| 参考素材 | 图≤9、视频≤3、音频≤3 | 图≤30、视频≤10、音频≤10 |
| 多镜表达 | **镜头编号式**（"镜头1：…镜头2：…"）——2.0 不识别时间戳 | **时间戳式**（"0-5秒：…"） |
| 音画 | 原生音画同步、口型同步（8+ 语言），台词写进镜头段 | 同左（11 语言），另有草稿模式（480p 预览） |
| 首尾帧 | 支持（防跨镜视觉漂移的关键） | 支持 |
| 续写/编辑 | — | 多轮续写延长、按时间戳编辑成品片段 |
| 分辨率 | 最高 2K，7 种画幅 | 最高 1080p（10-bit），mov 输出更稳 |

**免费档策略**：每天 10 次生成额度；草稿阶段用 seedance fast（低分辨率快速预览节奏与构图），参数确认后再用高质量模型出成片——比例/时长选错重跑等于浪费额度。

## 三、SOP 六步在豆包下的执行差异

### 第 0 步 资产准备
- 视图生成提示词（00 文件：主视角→俯视图→反打/补充视角→人物四视图）逐条粘贴进豆包对话生成。
- 参考图额度充裕：生成反打视角时把主视角图作参考图挂上（"参考@图片1的同一房间，从对面墙角看向中央"），一致性更好。

### 第 1-3 步 拆 shot 表 / 物理规则 / 分镜生成
- 01 物理规则、02 shot 表、03 分镜提示词的内容**完全不变**。
- 03 的分镜提示词在豆包用**组图模式**表达，把原"帮我生成4张…"开头替换为：
  ```text
  参考下面的空间逻辑图与人物资产图，以组图模式生成一组4张内容连贯的真人电影级别分镜图
  （同一场景、同一批人物、光线与色调一致，4张各自独立成图）。
  1️⃣ @图片1 是山羊头的全身形象参考图；……（其余挂载与物理规则原样保留）
  ```
- 验收照常（04 文件）；单张瑕疵直接在豆包对话里指出改动点重出，不整段重来。

### 第 4 步 拼版 → **省略**
- 组图模式 4 张独立成图，无需裁剪四宫格、无需九宫格拼版；04 文件中的拼版说明仅 RunningHub/本地 ComfyUI 路径需要。

### 第 5 步 空间锚定
- 俯视图仍然**必挂**（座位锚唯一事实来源）；Seedance 2.0 图参考≤9 的额度内，反打视角、桌面俯拍等补充视角可与俯视图同时挂载，不再需要"临时替换图4"。

### 第 6 步 视频出片（五锁 → 豆包格式转换表）

| 五锁 | 豆包表达 |
|---|---|
| [项目规格] | 生成参数：画幅 16:9、时长（2.0 选 10-15s / 2.5 选 15-30s）、模型（草稿 seedance fast，成片高质量档） |
| [STYLE LOCK] | 开头总述句："真人电影质感，昏黄钨丝灯光，胶片颗粒，全片人物样貌服装与@图片N严格一致" |
| [REFERENCE LOCK] | @图片1…逐张标注身份："@图片1 是山羊头面具人，唯一身份来源，不得出现其他清晰面孔" |
| [PHYSICAL/CONTINUITY LOCK] | 压缩成一句写进总述："封闭空屋无门无窗约30平方米、十人围圆桌、苏醒者低头撑桌不正脸直视镜头" |
| [SHOT 01~06] | **Seedance 2.0（镜头编号式）**："镜头1：…；镜头2：…"，每条视频 1-3 个镜头；**Seedance 2.5（时间戳式）**："0-3秒：…；3-5.5秒：…" |
| [AUDIO LOCK] | 台词直接写在对应镜头段内（原生口型同步）；音色跨段一致→挂音频参考；环境音写进镜头段 |

**豆包视频提示词成品模板（Seedance 2.0 镜头编号版）**：
```text
真人电影质感短片。全片昏黄钨丝灯光，胶片颗粒，场景为约30平方米封闭空屋，无门无窗，
墙面地板布满方格线条（与@图片1场景一致）。
@图片2 是山羊头面具人参考图，唯一身份来源，不得出现其他清晰面孔；
十人围圆桌，苏醒者一律低头撑桌、面部处于景深之外，不正脸直视镜头；
镜头1（0-3秒）：镜头缓推，昏暗空屋全景，大圆桌上十人围坐沉睡，山羊头立于一侧，静谧诡异；
镜头2（3-5.5秒）：座钟繁复花纹特写，指针指向十二，远处钟声，众人缓缓低头撑桌苏醒；
镜头3（5.5-10秒）：山羊头面具特写，发黄打结的羊毛，空洞眼窝里露出双眼，缓慢转头扫视，诡异压迫。
画面中不出现任何字幕、水印、文字标识。
```
- 用 Seedance 2.5 时把"镜头N（x-x秒）"改写为"x-x秒：…"时间戳即可，其余不变；
- **对话戏一镜一条**（单条只放 1 个镜头、10-15s），避免口型错乱；空镜/慢镜才一条多镜；
- 跨镜衔接：开启首尾帧——本条尾帧=下条首帧，或直接用 2.5 多轮续写；
- 台词较长时拆成多条，每条一个镜头一句台词，音色参考保持一致。

## 四、文字策略分级

| 工具 | 文字策略 |
|---|---|
| 豆包生图（Seedream 5.x） | 大字号短文字（招牌、个位号码、钟面数字）**可尝试直出**，验收不过再退回虚化；密集小文字（300块号码牌墙）仍一律虚化 |
| 豆包视频（Seedance） | 仍规避清晰文字，成片文字靠后期字幕 |
| ComfyUI/SD 系 | 全部虚化 |

## 五、豆包路径的坑（务必注意）

1. **Seedance 2.0 不识别时间戳**——多镜必须用"镜头1/镜头2"编号式表达；只有 2.5 才吃"0-5秒：…"语法。写错语法模型会忽略节奏指令；
2. 参考图多≠稳：视频实挂建议 **≤8 张**（图+音+视频合计），超过后一致性下降、生成变慢；
3. 免费档每天 10 次：参数确认后再生成；草稿用 fast 档省额度；
4. 首帧=分镜图时，分镜图里的虚化人群会被视频继承——虚化人群镜头的面部约束（低头/景深外/不正脸直视镜头）**必须同时写进视频提示词**；
5. 组图模式的 4 张图连贯但**不豁免物理规则**，仍按 04 清单逐张验收；
6. 对话戏贪多镜头=口型错乱，一镜一条是铁律；
7. 视频结果链接/生成记录有时效性，成片及时下载保存。

## 六、RunningHub 适配（教程原生路径）

> 云端 ComfyUI 平台，易大师教程的原始工作流所在。RHTV 无限画布把 Agent、工作流、素材节点串在一张画布上。

**SOP 各步在 RunningHub 下的执行**：

| SOP 步骤 | RunningHub 做法 |
|---|---|
| 资产出图（第0步） | 无限画布内串生图节点，或用 RHTV Agent 对话生成（Agent 会自动拆解：基准图→三视图→人物图→分镜） |
| 分镜生成（第3步） | 四宫格提示词投喂 → **裁剪拼九宫格（必做）** → 九宫格作为视频工作流的空间参考图槽 |
| 视频生成（第6步） | 选工作流/模板：MiniMax-H3 TURBO、Seedance 2.5/2.0、可灵等；参考图按**图槽**上传（通常 4 位：3 角色+1 场景锚） |
| 视频提示词 | 五锁结构**原样可用**（ComfyUI 路径的母本），粘贴进提示词节点 |
| 修复 | 改物理规则/提示词重新运行工作流，不抽卡 |

**独有增强**：
- **RHSTORY**：上传原片/参考图 → 角色、导演式剧本、智能分镜、3D 场景调机位——可替代本技能第 1-3 步的拆镜环节，但物理规则仍需本技能的 01 文件兜底；
- **Runow**：支持 Agent 与 Skill 接入，可把本技能产出直接投喂；
- **RH Upscale**：自研视频超分，出片后放大画质；
- **首尾帧 AI 应用**：跨镜衔接用现成模板。

**注意**：按积分/视频秒数计费，批量生成前先估算消耗；工作流图槽通常只有 4 图位，超过 3 个角色的场次按"焦点挂图+其余虚化"规则处理。

## 七、LiblibAI 适配（多模型聚合 + LoRA 训练）

> 国内最大模型社区（10 万+ LoRA/Checkpoint），一个账号聚合 Seedream 5.0 Pro、MiniMax H3 Image、Seedance 2.5/2.0、可灵 3.0 等主流模型。

**SOP 各步在 LiblibAI 下的执行**：

| SOP 步骤 | LiblibAI 做法 |
|---|---|
| 资产出图（第0步） | 极简生图器选 Seedream 5.0 Pro 等，多参考图（10-14 张）投喂本技能提示词；**角色一致性杀手锏：上传 200+ 张角色图在线训练专属 LoRA**，此后每镜直接挂 LoRA，不占参考图位 |
| 分镜生成（第3步） | 组图模式（部分模型支持）或逐镜生成；逐镜时每镜挂"角色 LoRA+场景图" |
| 后期修图 | 平台内置局部重绘、智能扩图、一键抠图、面部修复、提示词反推——分镜单点瑕疵不重生成，直接局部修 |
| 视频生成（第6步） | Seedance 2.5（30s 音画同出）/2.0（15s）/可灵 3.0 等按需选；语法同豆包 Seedance（2.0 镜头编号式、2.5 时间戳式） |
| 星流 Agent | 旗下智能体（无限画布+多轮对话编辑），可整链路自动化，物理规则提示词同样适用 |

**注意**：
- 视频模型语法跟豆包一致（同为 Seedance 系），转换规则见第 三 节；用可灵/海螺等其他模型时，五锁结构仍可投喂，但需按该平台时长上限（多为 5/10s）拆条；
- 免费用户每日登录送 20 积分，标准分辨率单图约 1 积分，跑全章资产需会员或算力包；
- 角色 LoRA 训练是本平台最大差异化优势：主角戏份贯穿多章时优先在 LiblibAI 训练 LoRA，再下载/调用，一致性远胜纯参考图。
