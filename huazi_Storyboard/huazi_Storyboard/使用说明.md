# huazi_Storyboard（分镜图制作 SOP）使用说明

> 版本：v1.3 ｜ 适用于任何支持 Agent Skills 规范（SKILL.md + YAML frontmatter）的智能体
> 技能内部标识名：huazi-storyboard（规范要求小写连字符）；显示与称呼名：huazi_Storyboard

---

## 一、这是什么

把"图生视频前先做分镜图"的完整方法论固化成的技能包。装上后，对智能体说一句话，它会：

1. 自动在工作区（或你指定位置）创建 **`{名称}分镜图设定/`** 文件夹（名称=小说名或你指定的名字）
2. 产出 6 个工作文件（00 素材清单 → 05 视频提示词），全部为 **.md**（可按需转 **.docx**）
3. 其中所有提示词（资产出图/分镜图/视频五锁）均为**完整成品**，直接整段复制即可投喂给 AI 画图模型或视频模型，无需任何二次加工

## 二、什么时候可以用（重要）

**拿到小说章节或大纲的那一刻就可以用，不需要任何前置准备。**

| 你的状态 | 能不能用 | 说明 |
|---|---|---|
| 只有章节正文 | ✅ 可以 | 技能自己拆分镜、写 shot 表、生成全部提示词 |
| 只有章节大纲/梗概 | ✅ 可以 | 技能按大纲推演画面细节，标注依据 |
| 有完整剧本 | ✅ 可以 | 直接按场景切分，对话戏自动设计正反打 |
| 已有人物卡/场景图资产 | ✅ 更好 | 给出路径直接引用，跳过补全步骤 |
| 什么都没有 | ⚠️ 先问 | 技能会先问清人物、场景、画风再开工 |

你不需要先自行：①生成人物图 ②分镜 ③写分场剧本——这些全部是技能的产出内容；人物/场景生图提示词也在产出里（中英双语，直接投喂画图模型）。

## 三、安装方法

### 方式 A：WorkBuddy（本机）

技能已默认安装在：
```
C:\Users\Administrator\.workbuddy\skills\huazi_Storyboard\
```
重启会话后生效。也可以在对话里说"安装 / 搜索 skill 分镜图"走技能市场流程。

### 方式 B：其他智能体（通用）

只要智能体支持 Agent Skills（SKILL.md 规范），把整个 `huazi_Storyboard/` 文件夹放进它的技能目录即可（部分平台要求目录名与 SKILL.md 内 name 字段一致，此时把文件夹改名为 `huazi-storyboard`）。常见位置：
- Claude Code / 类似 CLI：`~/.claude/skills/huazi-storyboard/`
- 其他平台：平台设置里的"技能/Skills"导入入口，选择 `huazi_Storyboard.zip`

### 方式 C：手动（任何智能体）

如果目标智能体不支持技能系统，把 `SKILL.md` + `references/` 三个文件的内容直接粘贴进它的系统提示词/知识库，效果等同。

## 四、怎么触发

对话里出现以下任意说法即可（无需记命令）：

| 你说 | 智能体会做 |
|---|---|
| "给《规则残响》做分镜图" | 创建"规则残响分镜图设定/"并产出全套文件 |
| "按SOP做第3章的分镜脚本" | 读取第3章内容 → 产出该章分镜 |
| "为我的小说做AI短剧分镜设定" | 先问清名称/章节/人物场景，再开工 |
| "帮我给XX故事做分镜图设定，放在D:/短剧/" | 在指定目录创建文件夹 |

**建议随话提供的输入**（缺了智能体会主动问）：
- 小说/项目名称（决定文件夹名）
- 章节/剧情范围（可给原文、大纲或文件路径）
- **画风**（必问项：电影写实风 / 3D动漫风 / 3D真人风 / 2D动漫风 / 国漫风等）——确认后所有资产卡、分镜图、视频提示词统一携带该风格词，全项目不混用，避免弄错风格二次生成
- 人物清单和场景清单（或指路已有的人物卡/美术资产文件）

## 五、产出文件说明

```
规则残响分镜图设定/
├── 00_项目信息与素材清单.md   人物表/场景表/资产盘点+资产命名与挂载对应表，缺啥一目了然
├── 01_空间物理规则总表.md     每个场景的"宪法"：尺寸/站位/人数/朝向/文字规避
├── 02_分镜总表_shot表.md      镜号|段|时长|景别|运镜|情节|情绪|节奏标注（爆点/爽点/反转/铺垫/钩子）全景总表
├── 03_分段分镜图提示词.md     ★核心：每段一条完整提示词，复制即投喂画图模型
├── 04_验收与拼版清单.md       逐格验收五项口诀+节奏验收+翻车修复对照表+九宫格拼版流程
└── 05_视频环节提示词_五锁结构.md ★核心：五锁结构视频提示词，复制即投喂视频模型
```

### 资产提示词规格（本技能的硬标准）

- **五件套**：每个资产（人物/场景/道具）的出图提示词都含中文对照、英文投喂、主形象纯图简版、版面排版说明、反向提示词
- **版面标注**：人物卡左上角代号，左43%主肖像/中三视图/下方特点（疤痕胎记等）与服装特写/右22%眉眼口鼻耳发型特写；场景与道具卡为锚点特写版面
- **浅色背景**：资产卡背景统一纯白或浅灰最佳，禁用深色
- **场景变体**：有变体（光照/时段/状态）逐个写完整变体提示词，不省略
- **命名对应**：资产代号（CH01-角色名 / S01-场景名-FP 等）在 00 对应表、03 @图片N、05 @ref_image_N 三处完全一致

### 工作顺序（拿到文件后怎么用）

```
03 里的"资产出图提示词"→ 出人物资产卡版面图/场景资产卡/俯视图（浅色背景，纯白或浅灰最佳）
        ↓
03 里的"分段分镜图提示词"→ @图片挂资产 → 画图模型生成四宫格分镜
        ↓
04 对照验收 → 不合格改01里的物理规则重新生成（不抽卡）
        ↓
四宫格裁剪拼九宫格 → 得到"分镜图资产"
        ↓
05 的五锁提示词 + 分镜图资产 → 投喂视频模型（MiniMax/Seedance/即梦等）
```

## 六、提示词的"成品保证"

本技能输出的每条提示词满足：
- **完整自包含**：任务指令、@图片分工、物理规则、shot 表、负面要求齐全
- **变量全部填好**：角色名、场景名、镜号内容、时长景别运镜全部落地，没有"请自行替换"
- **中英双语**（资产出图类）：中文供核对，英文块直接投喂
- **fenced code block 包裹**：一键复制不串行

## 七、常见问题

**Q：只有大纲/梗概没有正文，能用吗？**
A：能。技能会按大纲推演每镜画面动作与情绪并标注【依据大纲推演】，推演内容建议用户过目确认。

**Q：需要先自己把人物图/场景图生成好吗？**
A：不需要。资产出图提示词（中英双语）就是技能的产出之一，拿到后直接投喂画图模型即可。

**Q：一场戏超过 3 个角色怎么办？**
A：看工具：豆包/即梦（生图最多 10 张参考图、视频全能参考素材≤12）可全员挂资产，建议实挂≤8 张保稳；ComfyUI/MiniMax 路径每条只挂 3 个角色+1 张场景图，其余角色写入物理规则作为虚化背景。任何工具下：焦点角色占不到参考位时，在物理规则里显式固定其外貌并允许清晰呈现。

**Q：有什么限制？**
A：主要限制：①技能只产出提示词文本，出图出片需自备模型环境；②文字策略按工具分级：豆包/即梦大字号短文字可直出，ComfyUI/SD 系一律虚化，视频环节任何工具都靠后期字幕；③单条视频时长按工具分档：即梦 Seedance 5-10s/条（时间戳可写多镜、可延长），ComfyUI/MiniMax 10-15 秒/段；④超长章节建议按场景分批产出。详见 SKILL.md「限制与边界」。

**Q：能输出 docx 吗？**
A：默认 .md。对智能体说"转成 docx"即可；若环境没有文档转换能力，智能体会说明原因并保留 .md。

**Q：我想只做某一章/某一场戏？**
A：触发时说明范围即可，如"只做第2章的资料核验走廊那场戏"。

**Q：已经有美术资产/人物卡了，会重复生成吗？**
A：不会。在对话里给出资产文件路径（如 cast.md、美术资产设定集），智能体会直接引用并把资产状态标为"已有"。

**Q：技能会用哪个平台出图出片？**
A：若你没指明，智能体会**先问你**再产出（豆包 / 即梦 / RunningHub / LiblibAI / 本地 ComfyUI）——不同平台挂载数、拼版环节、视频语法差异很大。已适配五平台，速查表与逐环节差异见 `references/tool-adaptation.md`；流程总览见 `assets/技能使用流程图.svg`。豆包为默认主推路径：生图用组图模式（四宫格裁剪与九宫格拼版省略），视频用 Seedance（2.0 镜头编号式 / 2.5 时间戳式），台词口型原生同步。

**Q：文件夹想放到指定位置？**
A：直接说，如"放在 D:/短剧/小说生成/"。脚本支持 `--path` 参数。
